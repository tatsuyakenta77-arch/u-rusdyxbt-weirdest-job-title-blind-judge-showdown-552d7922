One job title, 36 characters, written the way a real posting is written — seniority, craft, clientele — with one gloriously odd twist:

> Senior Sorry Writer for Billionaires

A professional apology-writer whose clients are billionaires: someone who sits at a desk drafting grovelling notes while a billionaire dictates over the phone what he did this time. The apology-letter cousin of a speechwriter — a real craft, pointed at the funniest possible client, someone rich enough to never apologise in person. Short on purpose: 36 characters, five words, one breath.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single title to `/output/entry.txt` and prints exactly that title to stdout. No network, no randomness — every run writes the same bytes.
